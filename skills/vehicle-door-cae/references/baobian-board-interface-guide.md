# 包边与内外板共节点操作指南（HM17）

本参考将工程师提供的《包边和内外板合并指南》、其 5 张 HyperMesh 17 截图，以及已确认的现场修复经验转化为可执行边界。原始文件保存在 `knowledge/sources/baobian-neiban-waiban-interface-guide.docx`，对应可检索来源卡为 `hm17.source.baobian_neiban_waiban_interface_guide`。

## 2026-08-04 节点合并与局部修复补充

执行前还必须阅读 baobian-interface-node-merge-guide.md。该补充把现场节点合并与局部修复经验固化为以下强制约束：

- 自动候选只允许来自 baobian 的强内侧接口自由边；包边外侧自由边、真实外轮廓、与外侧段相邻或无法分类的边一律排除。
- 1.0 mm 仍是本指南的接口限定 Preview Equi 值。3.0 mm 只能形成工程师审阅距离报告，不能触发自动 Equivalence 或 Replace。
- 节点距离进入容差但未被合并时，先检查边界分类、组件/mark 范围和一对一拓扑；不要通过扩大容差绕过这些检查。
- 非拐角三角形和局部密度突变只能在目标板件的局部放大区域修复，不能重划或改变 baobian。

## 适用范围

仅用于已完成包边网格的 `baobian` 与一个相邻板件之间的共节点修复：

- `baobian` ↔ `neiban` 或 `neiban_midface`
- `baobian` ↔ `waiban` 或 `waiban_midface`

不把两个板件同时放入操作。先完整处理并验收一个接口对，再处理另一个接口对。

## 不可突破的约束

| 项目 | 规定 |
| --- | --- |
| 参考网格 | `baobian` 是主参考网格；不得移动、重划、合并或改变其节点、单元和几何。 |
| 可修改范围 | 只能在当前目标板件的已确认接口局部补网、combine、split、Automesh、Replace 和合并节点。 |
| 禁止操作 | 全模型 equivalence、三组件 equivalence、未预览的批量合并、修改接口以外网格。 |
| 工作次序 | 一次一个相邻板件；目标板件贴向 `baobian`，绝不反向。 |
| 阶段优先级 | 进入“包边—板件共节点”阶段后，本指南和 `hm17.mesh.interface_connectivity` 优先；此前的包边修网卡不能再打开对 `baobian` 的修改。 |
| 保存 | 操作前另存为日期/操作命名的恢复 `.hm`；保留 Tcl、变更数量和检查结果。 |

若实际模型没有明确的 `baobian` 主参考边界，或工程师希望改变包边本身，停止本流程并要求工程师重新指定主从关系。

## 闭环流程

### 0. 建立基线和范围

1. 确认活跃模型、求解器模板、MCP 状态、`baobian` 和目标板件名称。
2. 另存恢复模型，记录当前接口的节点数、单元数、异常自由边、重复单元和漏网区域；同时保存 `baobian` 接口的节点 ID、节点坐标、单元 ID 和单元连接关系基线。
3. 隔离当前接口对，标出真实外轮廓、待连接边界和内部异常自由边。真实外轮廓不是缺陷，不能因共节点操作而删除。

### 1. 先补齐缺网

若能看到几何面却没有单元，先只选该缺网面进入 `Automesh` 补网；不能为了补一个洞而重划整个组件。补网后立即检查是否形成新的自由边、重复面或质量恶化。

### 2. 先让边界拓扑一一对应

逐段比较 `baobian` 与目标板件的接口边：节点数、边段数、方向、局部单元尺寸和几何贴合。

只能修改目标板件：

- 目标侧节点过多：在局部将相邻小单元 `Edit > Element > Combine`，必要时在合并区域中央 `Edit > Split`，使边段数降到与包边一致。
- 目标侧节点过少或单元过大：在目标侧 `Split` 大单元或局部 Automesh，使边段数增加到与包边一致。
- 非拐角处的非必要三角形：和相邻四边形 `Combine` 后再 `Split`；拐角或无法避免的短过渡三角形必须留下原因。
- 局部尺寸明显不均匀：在目标侧合并连续小单元或分割过大单元，使尺寸平滑过渡，不得拿包边网格去迁就目标板件。
- 重复面/重复单元：先确认哪一层是重复的，只删除目标侧重复单元；删除后立即补齐可能暴露的孔洞。

节点数尚不一致时，不进入 equivalence 或 Replace；先返回本步骤。

### 3. 受控 Edge Equivalence

工程师指南的面板顺序是：选择 `comps` 中的当前组件对 → 输入容差 `1.000 mm` → `preview equi` → 复核候选 → `equivalence`。

1. 仅选择 `baobian` 和当前一个目标板件；不要同时选择 `neiban` 与 `waiban`。将两侧已确认接口的边/节点 ID 保存为本次候选边界集。
2. 将 `1.000 mm` 视为本指南接口的预览容差，而不是模型默认容差。
3. 必须先执行 `preview equi`。只有候选的两端都落在已保存的接口边界集内，才可视为接口候选；若预览出现接口外候选、真实外轮廓候选、三方候选，或不能证明 `baobian` 将保持不变，拒绝预览并回到局部拓扑调整。
4. 只有预览候选全部处于已确认接口，且工程师完成复核后，才执行 `equivalence`。

不要因为面板中的 `lowest id` 选项就假设包边会自动保留；必须以预览和执行后的读回检查确认 `baobian` 没有变化。

### 4. 用 Replace 清除残留错位

对 equivalence 后仍不共节点的少量位置，使用 `Edge > Replace` / 节点 Replace 逐对处理：选择目标板件节点作为被移动侧，并贴向对应的 `baobian` 节点；需要时勾选 equivalence。若找不到一一对应节点，说明拓扑仍不匹配，返回步骤 2，而不是扩大容差。

### 5. 闭环验收

完成当前板件后检查：

1. 包边—板件之间没有异常接口自由边。
2. 真实外轮廓自由边仍在；没有新内部自由边、漏网、重复面/重复单元或孤立节点。
3. `baobian` 的节点 ID、节点坐标、单元 ID、单元连接关系、几何和接口外区域与基线一致；任一差异都应回滚并交工程师判断。
4. 局部网格尺寸过渡均匀、几何贴合未变差，非拐角三角形已消除或有明确例外理由。
5. 保存节点数、单元数和自由边数量变化；失败则恢复到本接口开始前的 `.hm`。

通过后再从步骤 0 开始处理另一个板件。

## 症状到动作

| 现象 | 优先动作 | 不可做 |
| --- | --- | --- |
| 有面无网格 | 仅该面 Automesh | 整组件重网格 |
| 目标侧边节点更多/更少 | 目标侧局部 Combine + Split | 用大容差强行合并 |
| equivalence 后少量错位 | 逐对 Replace，目标贴包边 | 反向移动包边 |
| 接口有自由边 | 回查边段/节点对应，再修局部网格 | 删除真实外轮廓自由边 |
| 重复面 | 确认后删除目标侧重复单元 | 不检查就删除两层之一 |
| 非拐角三角形 | 与邻四边形 Combine 后 Split | 保留为默认解 |

## 必须停止并交给工程师的情况

- `baobian` 不是已确认的参考网格，或任何操作会改变它。
- Preview Equi 包含接口外候选、三方候选或真实外轮廓候选。
- 节点数/边段数不能在目标侧通过局部修复对应。
- 质量、几何贴合或自由边检查出现回归。
- 需要放大 `1.000 mm` 容差、跨组件批量合并，或无法解释剩余三角形/重复面。

这些情形只允许生成候选和审计证据，不能由 agent 自动宣称完成。
