# 包边—板件节点合并与局部修复（HM17）

## 不可改变的前提

baobian 是已验收的参考网格。所有补网、Combine、Split、局部 Automesh、Replace 与节点合并均只能修改当前一个目标板件；一次只处理 baobian 与 neiban 或 waiban 中的一对接口。

在操作前固定 baobian 的接口基线：节点 ID、节点坐标、单元 ID、单元连接关系、接口外区域和真实外轮廓自由边。

## 自由边分类

只允许将强内侧接口自由边用于自动候选。强内侧候选必须同时满足：

1. 是 baobian 上的自由边；
2. 位于工程师确认的包边—板件接口带内；
3. 有对应目标板件的边界或节点，并且局部拓扑可形成一对一对应；
4. 不属于零件真实外轮廓；
5. 不与外侧自由边段相邻、不重叠，也不存在分类不确定性。

以下对象一律排除：包边外侧自由边、真实外轮廓、与外侧段相邻的边、局部多个目标节点争抢同一参考节点的边、以及无法证明属于接口的边。距离最近或处于容差内并不能使被排除对象重新成为候选。

## 节点匹配方向

1. 只收集目标板件上已确认接口自由边的节点；不要把目标板件其它外轮廓或内部节点加入 mark。
2. 对每个目标节点，只在 baobian 的强内侧接口自由边节点集合内寻找最近节点。
3. 先建立候选表：目标节点、参考节点、距离、两侧边段、边界分类、局部单元尺寸和一对一配对状态。
4. 仅当距离不超过已批准容差且配对唯一时，才允许把该行送入 Preview Equi 或逐对 Replace。
5. Replace 的方向固定为目标板件节点贴向 baobian 节点；baobian 节点不移动。
6. 多个目标节点对应一个 baobian 节点、一个目标节点对应多个参考节点、或节点数不相等时，不执行合并，先回到目标板件侧局部修复。

## 容差与未合并节点

工程师指南中的 1.0 mm 仅用于已确认单一接口对的 Preview Equi。不得为了增加自动匹配率将其提升为 3.0 mm 并直接执行 Equivalence 或 Replace。3.0 mm 只能用于生成工程师审阅候选和距离报告。

容差内节点没有合并时，按以下顺序诊断：

1. 目标节点是否为目标板件的真实接口自由边节点；
2. 最近 baobian 节点是否属于强内侧接口自由边，而不是外侧或内部节点；
3. 两侧边段数、节点数和方向是否一对一对应；
4. 当前 mark、组件范围和命令选择是否实际包含该节点；
5. 是否存在多对一或一对多歧义。

任一项不满足时，先在目标板件侧修复拓扑，不扩大容差。

## 局部三角形和网格密度处理

连接处出现非拐角三角形、异常小单元、明显尺寸突变或无法一一对齐时：

1. 只在目标板件上选择包含问题单元及其相邻过渡单元的局部放大区域；
2. 通过 Combine + Split 先调整简单拓扑；若不足，再对该局部区域 Automesh；
3. 以 baobian 已有边界节点和局部尺寸为约束，重建目标板件侧的节点数和边段数；
4. 重新分类自由边、复核一对一对应后，再执行 Preview Equi 或逐对 Replace。

不得把 baobian 一并重划，不得为了修复局部三角形而重划整个组件，也不得把外侧自由边并入修复区域。

## 停止条件

出现外侧候选、分类不确定、三方合并候选、baobian 基线变化、无法一对一对应，或局部重划后质量/贴合回归时，停止自动修改并提交候选、局部证据和恢复文件给工程师。
